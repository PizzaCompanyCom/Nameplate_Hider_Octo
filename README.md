**Totem & Pet Nameplate Hider v1.4.2**
World of Warcraft — OctoWoW 1.17
A lightweight addon that automatically hides unwanted nameplates to reduce screen clutter.

**Features:**
Hide friendly and enemy Shaman Totems.
Hide Hunter and Warlock Pets.
Hide enemy players without PvP enabled.
Optionally hide regular NPC nameplates.
Customizable settings window.
Movable minimap icon with saved position.
Individual filters with saved settings.

**Commands:**
Command
Description
/tpnh
Open settings
/tpnh config
Open settings
/tpnh status
Show addon status
/tpnh debug
Toggle debug mode
/tpnh inspect
Inspect detected nameplates
/tpnh learn
Learn selected pet name
/tpnh add Name
Add name to hide list
/tpnh remove Name
Remove name from hide list
/tpnh exclude Name
Exclude name from filtering

**Minimap Icon:**

Left Click: Open/close settings.
Right Click: Enable/disable filtering.
Drag: Move the icon around the minimap.

Note: Some filters may be limited by the OctoWoW 1.17 client API.
